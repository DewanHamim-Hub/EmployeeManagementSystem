# Employee Management System
### Developed for Jagoran Security Service

A role-based web application built with ASP.NET Core MVC (.NET 8) designed for a security guard providing company. The system streamlines employee management, attendance tracking, shift scheduling, and automated salary calculation.

## Technologies Used
- ASP.NET Core MVC (.NET 8)
- C#
- Entity Framework Core
- Microsoft Identity (ASP.NET Core Identity)
- Microsoft SQL Server
- HTML, CSS, Bootstrap

## Roles & Features

### Admin
- Manage employees
- Manage attendance
- Manage shifts
- Manage clients
- Manage duty assignments
- Manage and view salary details

### Employee / Guard
- View assigned duties
- View personal salary details

## Salary Calculation
Salaries are calculated automatically based on assigned shifts and attendance/absence records.
